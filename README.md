# Tasmac - Liquor & Inventory Management System

This project was built with [Lovable](https://lovable.dev) and [TanStack Start](https://tanstack.com/start).

## Overview

TASMAC Inventory & Management platform designed for stock tracking, store management, and analytics.

## Development

To get started with local development:

```sh
# Clone the repository
git clone https://github.com/Rabil009/Tasmac.git
cd Tasmac

# Install dependencies
npm install

# Run the development server
npm run dev
```

## Available Scripts

- `npm run dev`: Starts the development server with Vite
- `npm run build`: Builds the production bundle
- `npm run test`: Runs test suite with Vitest
- `npm run lint`: Lints project code with ESLint
- `npm run typecheck`: Validates TypeScript types

## Tech Stack

- **Framework**: TanStack Start / React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database / Backend**: Supabase & Drizzle ORM
- **Tooling**: Vite & Vitest
